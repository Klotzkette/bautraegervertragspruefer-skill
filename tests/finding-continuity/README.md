# FC01 – Vollständige Übernahme in die Schreiben

Diese begrenzte Schreibprobe gibt eine bereits geprüfte Befundlage nach Vertragsrücklauf vor: zehn offene Punkte, zwei erledigte Teilbefunde und zwei positive Kontrollen. Sie prüft die tatsächliche Übernahme in Mandantenschreiben und adressatengerechte externe Entwürfe einschließlich einer gegebenenfalls gemeinsamen, vollständig ausgearbeiteten Anlage.

Ausführende erhalten nur den zu prüfenden Prompt und [input.md](input.md). [erwartungen.json](erwartungen.json) bleibt bis zum Abschluss verborgen. Keine vorangehenden Modellantworten oder Gitgeschichte mitgeben.

Die Probe ersetzt weder eine blinde eigene Vertragsanalyse noch einen vollständigen DP01-Nachtest. Die [Ausführung vom 25. September 2026](../runs/2026-09-25/README.md) dokumentiert Rohtexte, Instruktionsstände und Bewertung getrennt.
