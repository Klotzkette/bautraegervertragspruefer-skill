# Technische Normreferenzen und Verjährung

Gezielte Gegenprobe nach einer im DP01-Lauf unkritisch übernommenen Elektro-Klassenbezeichnung. Nur [input.md](input.md) wird dem ausführenden Modell mit seinem Prompt gegeben; [erwartungen.json](erwartungen.json) bleibt ausschließlich der nachträglichen Auswertung vorbehalten.

Vier Ausschnitte prüfen eine fehlerhafte DIN-/RAL-Zuordnung, eine fachlich richtig kombinierte Gegenfassung mit fehlender Anlage, konkrete Fenster-/Türzusagen sowie eine formularmäßige Bauwerksverjährung von 24 Monaten. Die ausdrückliche Begrenzung auf diese Ausschnitte darf kein vollständiges Standardpaket auslösen.

Die [tatsächlichen Läufe vom 25. September 2026](../runs/2026-09-25/nr01-auswertung.md) sind eine gezielte Nachprüfung, kein Ersatz für einen erneuten vollständigen Vertragsdialog.
